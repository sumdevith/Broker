# Chapter V — Founder Sprint 01 (18–24 November 2026)

## Goal
Define the first realistic international market entry and product prototype; set up reproducible documentation. **Zero real-money exposure.**

- [ ] **Day 1:** Write one paragraph on global vision and customer problem; list features we refuse to promise (guaranteed returns, unrestricted countries).
- [ ] **Day 2:** Choose one asset class and persona; compare 3 competitors' education/demo products.
- [ ] **Day 3:** Pick 3 candidate launch/partner jurisdictions. Identify authorities and classification of chosen product.
- [ ] **Day 4:** Draft 10 customer stories, 10 acceptance checks and exclusions for demo MVP.
- [ ] **Day 5:** Diagram quote ingestion → risk → simulated order → event ledger → portfolio.
- [ ] **Day 6:** Plan local setup, documentation, test conventions, secure secrets handling and branch discipline.
- [ ] **Day 7:** Record evidence, unresolved questions, counsel outreach plan and Sprint 02 backlog.

## Decision questions
1. What first asset class: forex/gold CFDs, exchange-listed securities, futures or crypto?
2. What first target user segment: retail beginner, active trader or B2B broker clients?
3. What is the available **non-essential** engineering budget, separate from regulatory capital?
4. Which markets are candidates for **licensed partnership first**, and why?
5. Which account and support languages are needed?

## Definition of done
- Repo README and 6 chapters committed.
- Market and user persona selected with rationale.
- Jurisdiction matrix has at least 3 candidates, clearly marked as not approved.
- Requirements and first month of GitHub issues ready for discussion.
